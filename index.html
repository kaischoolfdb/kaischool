Setup Guide

1. Email Notifications (EmailJS)
Sign up at emailjs.com. Create an email service, then a template with variables like {{student_name}}, {{subjects}}, etc. Copy the Public Key, Service ID, and Template ID into the fields above.

2. Google Sheets Logging
Open script.google.com, create a new project, paste the Apps Script code (see below), deploy as Web App, and paste the URL above.

3. Voice on All Browsers
Chrome and Edge support voice natively. For Firefox/Safari desktop, get an API key from platform.openai.com and paste it above.

Google Apps Script Code: 
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.appendRow([
    data.id, data.student, data.email || "", data.phone || "", data.decision, data.timing,
    data.factors.join(", "), data.subjects.join(", "), data.teacherName,
    data.satisfaction, data.conditions, data.teacher,
    data.reception, data.admissions_staff, data.exp_teachers,
    data.exp_students, data.exp_facilities, data.class_atmosphere,
    data.tuitionImportance || "", data.tuitionChange || "",
    data.enrollment, data.curriculumLikes || "", data.positive, data.negative, data.almostEnroll,
    data.comments, data.date
  ]);
  return ContentService.createTextOutput(JSON.stringify({result:"ok"})).setMimeType(ContentService.MimeType.JSON);
}
